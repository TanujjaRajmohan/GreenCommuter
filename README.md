GreenCommuter

A Python desktop application that encourages sustainable commuting through personalised travel recommendations, CO₂ tracking and gamified rewards.

## Features

* Personalised commuting recommendations: walking, cycling, public transport and carpooling.
* Estimated CO₂ savings compared with driving alone.
* Points, consecutive-day carpool bonuses and individual rewards.
* Personal progress tracking and shared company sustainability goals.
* CSV-based employee and commute data management.
* Desktop interface built with Tkinter.

## Tech Stack

* Python
* Tkinter
* CSV file handling

## How It Works

The application uses commuting distance, public transport stop proximity and colleague availability to recommend a suitable travel option. It estimates carbon savings and rewards employees for choosing greener journeys.

## Future Improvements

* Live public transport information.
* Weather-aware travel recommendations.
* Team leaderboards and interdepartmental challenges.

## Disclaimer

CO₂ savings are estimates based on the emission factors and assumptions used by the application. This project is a prototype and has not independently verified real-world emissions reductions.
